# Shivam Sharma | Data Analytics Portfolio

A responsive Data Analytics portfolio created with Next.js 15, React 19, Tailwind CSS 4, GSAP 3 and Lenis.

## Local development

```bash
npm ci
npm run dev
```

Project details use verified information supplied by Shivam. Project thumbnail graphics are illustrative placeholders; actual dashboard screenshots should be uploaded before sharing the website. Power BI dashboard remains a work in progress.

## Deployment

Deploy on a Next.js-capable platform such as Vercel. Set `NEXT_PUBLIC_SITE_URL` to your published domain. Contact form delivery requires `RESEND_API_KEY` or `GMAIL_APP_PASSWORD` plus `CONTACT_EMAIL`. Do not commit secrets.
